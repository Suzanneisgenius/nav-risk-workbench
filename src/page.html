How to import multiple accounts

Select one or more CSV, XLSX or XLS files. Include account, date and a positive nav or eq column. Without an account column, the filename identifies the account. Your first import replaces the synthetic workspace. Later imports merge by account and date, with the latest incoming row winning. In Scoring settings, enable combined NAV to compare the accounts on their shared dates.

For a practice file, download the Excel template or the repository’s demo CSV. Each saved snapshot contains all loaded accounts.

Source and methods

This separate course project by Joylyn Qiao and Zun Cao aligned adjusted-close daily returns from Yahoo Finance. The embedded notebook snapshot contains 5,536 trading dates from August 1, 2002 through July 30, 2024. Windows use prior observations from the full history, even when the chart shows a shorter period. Returns are in percentage points. Daily volatility is a 30-session sample standard deviation.

How the lab flags a slowdown

The gap is the 10-observation slope minus the 3-observation slope, expressed as a percentage of current NAV per observation.

A gap above 0.20 prompts a watch. It becomes a warning when the short slope is also negative. Any gap above 0.35 triggers a strong warning. These standalone thresholds are fixed in both alert modes.
